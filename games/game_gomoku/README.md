# 五子棋

> 全局快捷键：`M` 静音，`-` / `+` 调节音量，`F11` 切换全屏。

[返回小游戏合集](../../README.md)

五子棋采用 15×15 的古朴木质棋盘与传统黑白棋子。当前最小版本完整支持本地双人对战；
人机模式入口已经保留并标注为开发中，AI 将在后续阶段实现。

## 当前功能

- 本地黑白双方轮流落子
- 横向、纵向和两种斜线五连胜负判定
- 最近一步标记与获胜连线提示
- 对局中或胜负结束后悔棋
- 重新开始和重新选择模式
- 响应式木棋盘、落子预览和黑白棋子立体绘制
- 落子、悔棋和获胜音效
- 全局音量、静音和全屏设置
- 人机模式入口与“AI 开发中”状态提示

## 操作

| 操作 | 功能 |
| --- | --- |
| 鼠标左键 | 在棋盘交叉点落子 |
| `U` 或 `Backspace` | 悔棋 |
| `R` | 重新开始当前模式 |
| `1` | 在模式选择中启动本地双人对战 |
| `2` | 查看人机模式开发提示 |
| `Esc` | 关闭模式选择或返回合集菜单 |

核心落子、胜负判断与悔棋规则位于 `logic.py`，不依赖 Pygame。
