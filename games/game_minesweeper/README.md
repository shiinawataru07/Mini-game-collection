# 扫雷

[返回小游戏合集](../../README.md)

扫雷是本合集中的第三个游戏。玩家需要翻开所有安全格，并利用数字推断地雷位置。当前实现包含三种经典难度、首次点击安全、空白区域连锁展开、数字快捷展开、双语界面、多套主题和各难度最佳时间记录。

## 游戏功能

- 初级：9×9，10 个地雷
- 中级：16×16，40 个地雷
- 高级：30×16，99 个地雷
- 第一次翻开的格子及周围八格不会生成地雷
- 零相邻雷区域自动连锁展开
- 支持插旗、取消旗帜和剩余雷数显示
- 点击已翻开的数字可快捷展开周围格子
- 错误旗帜可能在快捷展开时触雷
- 当前用时和各难度历史最佳时间
- 经典、森林和夜间三套主题
- 中文和英文界面
- 响应式窗口和整数像素方格

## 操作方式

| 操作 | 功能 |
| --- | --- |
| 鼠标左键 | 翻开格子；点击已翻开的数字执行快捷展开 |
| 鼠标右键 | 插旗或取消旗帜 |
| `R` | 重新开始当前难度 |
| `1` / `2` / `3` | 切换到初级、中级或高级并开始新局 |
| `S` | 打开或关闭设置 |
| `Esc` | 关闭设置；设置未打开时返回游戏选择界面 |
| 菜单、设置、重开按钮 | 执行对应操作 |

## 规则说明

游戏在第一次翻开格子时才生成地雷，因此首次点击及其周围八格一定安全。数字表示该格周围八个位置中的地雷数量。翻开数字为零的格子会自动展开相邻区域。

当一个已翻开数字周围的旗帜数量与数字相等时，再次左键点击该数字会翻开其余相邻格。如果旗帜位置错误，快捷展开可能直接触发未标记的地雷。

翻开所有非地雷格即可获胜，不要求手动标记全部地雷。获胜后会自动标记剩余地雷；失败后会显示全部地雷、爆炸位置和错误旗帜。

## 设置与玩家数据

打开设置时计时暂停。设置中可以：

- 切换初级、中级和高级难度；切换难度会开始新局
- 选择经典、森林或夜间主题
- 切换中文和英文界面

各难度最佳时间、当前难度、主题和语言保存在游戏目录的 `.player_data.json`。该文件是本地运行时数据，已被 Git 忽略。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `logic.py` | 延迟布雷、数字计算、连锁展开、插旗、快捷展开、胜负和计时 |
| `persistence.py` | 各难度最佳时间和玩家偏好 |
| `config.py` | 难度、主题、双语文案和窗口配置 |
| `ui.py` | 响应式棋盘、格子状态、设置和结果界面绘制 |
| `game.py` | 鼠标与键盘输入、计时暂停、记录更新和主循环 |
| `preview.py` | 合集菜单中的扫雷预览图 |

核心规则不依赖 Pygame，可以独立验证首击安全、布雷数量、相邻雷数、连锁展开、快捷展开和胜负条件。
